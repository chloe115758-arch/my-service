# CLAUDE.md

## 서비스 소개
오늘 걷기 좋은지 3초 만에 알려주는 작은 웹서비스.
사용자: 퇴근 후 걸음수를 채워야 하는 사람.

## API 규칙
- 인증키가 필요 없는 API만 사용한다. 키나 비밀번호를 코드에 넣지 않는다.
- API 주소와 요청 항목은 공식 문서에서 확인한 것만 쓴다. 추측해서 쓰지 않는다.
- 데이터를 기다리는 동안 "로딩 중" 화면을 보여준다.
- 불러오기에 실패하면 "불러오기 실패" 화면을 보여준다.
- 화면에 데이터 출처(이름과 링크)를 항상 표시한다.

## 내 서비스 규칙
1. 화면 맨 위에는 숫자가 아니라 "걷기 좋아요 / 보통이에요 / 쉬는 게 좋아요" 중 한 줄 판단을 먼저 보여준다.
2. 기온·비·미세먼지 같은 숫자는 판단 아래에 근거로만 작게 보여준다.
